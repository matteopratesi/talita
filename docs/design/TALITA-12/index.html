Mockup di TALITA-12 · Il menù della convivenza

Il file del menù della convivenza, solo per i maestri: la scheda nel dettaglio, la pagina per caricarlo o sostituirlo, il dialogo «Togli» e il collegamento in Arrivi. Nove pagine statiche con dati sintetici, da aprire direttamente nel browser, anche senza rete. Dove il mockup e il testo dei commenti non vanno d’accordo, vale il testo.

Convivenza e Arrivi

  • Dettaglio della convivenza · scheda «Menù» senza file

    Criterio 1. Senza file: «Nessun menù caricato.», una riga che dice a cosa serve e «Carica il menù» (secondario: la pagina ha già «Copia il link» come primario). La scheda sta dopo «Iscrizioni», prima delle schede dei dati.

  • Dettaglio della convivenza · scheda «Menù» con il file

    Criteri 1, 2, 7, 8. Con il file: nome, tipo, dimensione e data, «Scarica» (secondario), «Sostituisci» e «Togli» (testo) e la riga sulla riservatezza. In cima l’avviso dopo il caricamento (lo stesso «Menù caricato.» vale per la sostituzione; dopo «Togli» l’avviso è «Menù tolto.»).

  • Dettaglio della convivenza · dialogo «Togliere il menù?»

    Criterio 6. Il dialogo (bottone di pericolo: il file si cancella) dice cosa succede e cosa resta. Senza JavaScript «Togli» porta a una pagina con le stesse parole. Il bottone dice «Togli il menù».

  • Arrivi · il collegamento «Menù»

    Criterio 9. Sotto «Da stampare» una scheda «Menù» con una riga che scarica il file (icona di scarico al posto della freccia, nessun collegamento a un’altra pagina). Senza menù la scheda non c’è; con la sola bozza Arrivi non ha liste, quindi nemmeno questa. Nel mockup il collegamento non scarica niente.

Pagina del menù

  • Pagina del menù · senza file

    Criteri 2, 3. Il modulo di caricamento: avviso sui dati, campo per il file (PDF, JPEG o PNG, fino a 10 MB), «Carica il menù» e «Annulla». Il campo è quello nativo del browser; il modulo parte senza htmx e funziona anche senza JavaScript.

  • Pagina del menù · con il file (sostituzione)

    Criterio 6. Sopra il modulo c’è il menù di adesso (nome, tipo, dimensione, data); il nuovo file prende il suo posto. Titolo e bottone dicono «Sostituisci il menù».

  • Pagina del menù · il file sta partendo

    Criterio 2 (feedback). Dopo il tocco il bottone dice «Sostituzione…» e non si tocca di nuovo, la barra in cima compare dopo 300 ms e la pagina si attenua. Il campo del file è disegnato con un nome scelto solo per il mockup (quello vero è il campo nativo).

  • Pagina del menù · tipo sbagliato

    Criteri 3, 4. Risposta 422 con il file di un altro tipo: errore sotto il campo (il fuoco va al campo), il menù di prima resta e il file va scelto di nuovo (il browser lo svuota). «Nessun file» ha lo stesso aspetto, con «Scegli il file del menù.».

  • Pagina del menù · file troppo grande

    Criterio 4. Da 10 MB + 1 byte, e anche oltre i 20 MB del contenitore (in quel caso si arriva con un 303 e la pagina è identica): lo stesso errore sotto il campo, nessun file salvato.
